OpenGeni

Open-source runtime for durable, long-running AI agents with persistent sessions, isolated execution, recovery, approvals, and run history.

The innovative part: Agent runs are stored as replayable workflows, so they can continue after a process or connection failure instead of starting again.

Hackathon angle: Build a durable workflow agent for one narrow domain and demo interruption, recovery, approval, and proof that the task finished correctly.

CoreSpeed

A shared MCP layer that gives several coding agents the same connected apps, accounts, memory, usage limits, activity history, and approvals.

The innovative part: The common capability layer sits outside each model, so different agents can share tools and context while one external policy controls what each agent can use.

Hackathon angle: Build a capability wallet for a group of agents, with scopes, budgets, approvals, and live revocation for each connected service.

Fabrement

A WordPress agent that converts prompts, screenshots, or Figma designs into native Gutenberg blocks, templates, pages, forms, menus, and site changes.

The innovative part: It converts design intent into native platform objects under structural rules and reuses the existing design system instead of creating a separate page-builder format.

Hackathon angle: Apply the same compiler idea to another ecosystem: design input to native Shopify sections, React design-system components, or CMS blocks with review and rollback.

Octri.dev

A small API platform where one API specification generates documentation, SDKs, an MCP server for agents, and production monitoring.

The innovative part: One schema controls the human documentation, programmatic clients, agent tools, and monitoring, which keeps all four surfaces synchronized as the API changes.

Hackathon angle: Build a schema compiler for a narrow domain where one definition generates a human interface, agent tools, access rules, and monitoring.

Tokenectomy Razor

A small Rust MCP and stream processor that filters coding-agent logs before they enter model context, reducing repeated framework noise and retaining useful error frames.

The innovative part: It performs deterministic local filtering before model inference, so repeated or low-value log text does not consume the agent context window.

Hackathon angle: Build a general context filter for agent tool output and measure task quality and context use before and after filtering across shell, browser, and network logs.

Observer AI

Solo-dev open-source micro-agent system for passive monitoring. A controller agent turns a plain-English request into a small local watcher that loops over screen, camera, mic, clipboard, or memory and fires actions such as SMS, Telegram, email, calls, logging, or recording when a condition becomes true.

The innovative part: It separates the expensive one-time planning step from the cheap continuous loop. A larger agent configures a narrow micro-agent; then a small local model repeatedly evaluates only the sensor state it needs. That makes 'watch this until X happens' practical without keeping a frontier model or a human in the loop.

Hackathon angle: Build a vertical event agent instead of another chatbot: lab experiment watcher, CI approval sentinel, robotics pit monitor, accessibility assistant, or anti-distraction coach. The demo is strong because judges can cause the event live and watch the action trigger.

ClosePaw

Small open-source Android phone-use agent that works against the apps and accounts already on your phone. It has a floating Smart Capsule for pause/takeover, per-app approval, and optional background execution through a virtual display.

The innovative part: The background virtual-display mode is the important part: the agent can operate Android without taking over the screen you are actively using. Pair that with an always-visible pause/takeover surface and hard blocks for sensitive apps, and phone-use starts to look like a usable delegated worker rather than a demo that hijacks your device.

Hackathon angle: Pick one mobile workflow that is painful because it has no API — returns, appointment rescheduling, field-service checklists, campus admin — and let an agent run it in the background while the user keeps using the phone.

cubefarm

New open-source 'software company' where a CEO agent studies a repo, writes the QA checklist and GitHub issues, proposes hires, developer agents work the issues, and QA agents test pull requests in a real browser before the office can merge them. The whole pipeline is visible as a 3D cartoon office.

The innovative part: The 3D office is not only decoration: it exposes the actual control loop. Planning, delegation, implementation, browser verification, screenshots, and merge gates become visible roles and places. That gives humans observability over a real multi-agent workflow instead of a wall of terminal tabs.

Hackathon angle: Use the same 'visible organization' pattern for a non-code domain — research lab, incident-response room, robotics scouting team, or due-diligence desk. A judge can literally walk through the agent workflow while it runs.

Bountora

Experimental job board for AI agents. Jobs have strict acceptance tests; agents discover work, bid, submit deliverables, and the system verifies the result. The full agent-facing surface is intentionally tiny: discover, create, bid, submit over MCP/REST.

The innovative part: The key primitive is not the marketplace UI. It is machine-verifiable settlement: the job includes a test that decides whether submitted work counts. That changes agent-to-agent delegation from 'trust the other agent' into 'pay or award only when an objective verifier passes.'

Hackathon angle: Build a narrow agent labor market where outputs are easy to verify — benchmark fixes, data extraction, web QA, puzzle solving, or code patches. Add reputation based on verifier pass rate rather than likes.

clodfarm

Fresh open-source farm for Claude Code agents. You give it a mission, it splits work into sub-agents, runs across multiple boxes/accounts, exposes the farm over MCP, alerts on failures, and only lands work when your verification command passes.

The innovative part: Its scheduler treats subscription limits as compute capacity. Each seat has its own real 5-hour and weekly budget, so the farm paces and routes work around quota pressure instead of letting one agent burn the whole allowance. It is effectively a cluster scheduler for human-owned agent subscriptions.

Hackathon angle: Generalize the scheduler: route tasks across paid frontier agents, cheap APIs, and local models based on remaining quota, latency, and task difficulty. Show the queue continue draining even when one provider rate-limits you.
