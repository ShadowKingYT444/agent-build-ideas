# Agent Build Scout — 2026-10-18

Five independent projects ranked for technical novelty, useful mechanisms, and hackathon potential.

1. **Sphinx** — An independent examiner reads a coding-agent diff and asks the human to predict edge-case behavior before a protected Git push. Hackathon: a robotics-code comprehension gate. https://github.com/parthh01/sphinx
2. **InBox Wall** — A read-only email pipeline hides suspicious CSS and Unicode payloads from downstream AI agents, with an isolated quarantine store and audit view. Hackathon: an input firewall tested with harmless injection canaries. https://github.com/Annora998/inboxwall
3. **Spomory** — Cross-agent knowledge graph using triple extraction, graph retrieval, and a learned policy for updating or retiring facts. Hackathon: compare fact-correction rules against learned memory updates. https://github.com/yliuai/spomory
4. **Shipback SFTP** — Agent deployments backed by saved original files, hash-checked previews, and conflict-aware reversal. Hackathon: reversible CRM updates with concurrent user edits. https://github.com/aldohushi1-stack/shipback-sftp
5. **Epoptes** — Agent job runner with interview-generated harnesses, bounded fresh-context cycles, feedback-driven replanning, and progress reports. Hackathon: a supervised research experiment conductor. https://github.com/ramigb/epoptes
