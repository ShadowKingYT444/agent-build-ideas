# Agent Build Scout — 2026-10-23

Five niche agent projects, ranked for novelty, usefulness and hackathon scope. Original sources are linked; limitations are not omitted.

## 1. Hycli — Turn websites into typed agent operations
Source: https://github.com/Hybirdss/Hycli
Mechanism: Three workers inspect documentation, JavaScript and browser-network evidence to synthesize CLI/MCP read and write actions. Read actions are checked; account-changing writes are not executed during preparation and require explicit per-site permission.
Adaptation: Compile typed actions for one campus site. Compare task reliability and permission failures with screenshot-driven automation.
Caveat: Undocumented endpoints change, and account-safety claims require independent audit.

## 2. The Enron Brain — Reconstruct what an organization knew at a given date
Source: https://www.thisandthat.chat/enron/
Mechanism: The maker processed 45,047 public Enron emails into 214 entity pages and 49,401 facts, each linked to the source email, and expires dated facts when the corpus establishes a change.
Adaptation: Build a timestamped, source-linked decision history for a public project. Test stale-fact detection with labeled cases.
Caveat: Reported accuracy was evaluated by another AI, not an independent audit.

## 3. Whiteboard — Source-linked software diagrams for agent review
Source: https://github.com/devdotfast/whiteboard
Product Hunt launch: https://www.producthunt.com/products/whiteboard-5
Mechanism: An agent SDK renders interactive architecture diagrams, semantic code diffs and session traces on a shared canvas; selecting a node takes reviewers to its source.
Adaptation: Show robotic autonomous routes with a click-through to code, log events and verification checks.
Caveat: The maker says diagrams are currently snapshots rather than fully live-synchronized.

## 4. Legalnaut — Cross-document contradictions with exact evidence
Source: https://legalnaut.com/
Mechanism: Extract dated claims from scans, archives and email; show opposing quotations side by side, anchored to original file, page and checksum, before a human approves the finding.
Adaptation: Investigate conflicting eyewitness reports and instrument logs after a robotics incident; score citation and conflict accuracy.
Caveat: Disagreement is not proof of falsehood; human judgment is required.

## 5. Sonah — Check what an agent actually did, not just its code diff
Source: https://github.com/getsonah/sonah
Mechanism: Compare Claude Code/Codex session records and actual command results with the user's requirements and repository diff. Highlight missing tasks and unauthorized decisions.
Adaptation: Build an agent-task-contract checker that detects misleading “tests pass” summaries by matching claims with tool execution traces.
Caveat: Independent LLM review still makes mistakes, and session logs may contain secrets.
