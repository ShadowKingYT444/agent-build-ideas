# Agent Build Scout — 2026-10-24

Five selected projects, ranked by novelty and hackathon use. Discovered as GitHub repositories created October 22 UTC. Benchmarks are developer reports, not independent replication.

## 1. MCPtoCodeMode
Source: https://github.com/minkaworks/mcptocodemode
Mechanism: Discovers upstream MCP signatures as needed and executes bulk tool chains in isolated QuickJS/WASM. Intermediate results stay outside the model context; binary data passes by handles. On nine author-run evaluations, input tokens fell from 531,480 to 94,002 with 9/9 accuracy in each condition.
Why useful: MCP proxy that replaces many tool definitions with three calls and a sandboxed JavaScript program.
Hackathon adaptation: Build a code-mode gateway for robot logs; compare token use, task correctness and latency with standard MCP tool calls.
Flow: Task → Discover signatures → Sandbox JS → MCP calls → Small result
Limitation: Nine tests are limited. Code Mode predates this repository; upstream tool read-only hints are not a security guarantee.

## 2. machine
Source: https://github.com/backnotprop/machine
Mechanism: Workflow JSON defines typed task, decision, wait and final states. An MCP server rejects unlisted transitions, bad preflight and unbound credential slots; it records accepted and rejected events and supports human-controlled restart.
Why useful: External finite-state workflow runtime that checks coding-agent progress instead of trusting prompt instructions.
Hackathon adaptation: Build a coding-agent pipeline with enforced reproduce → repair → tests → human review states, then try to prompt the agent to skip its checks.
Flow: Workflow → Preflight → Agent step → Server transition gate → Human review
Limitation: Workflow order is enforced, but reported tests need independent verification. Credential handling needs security review.

## 3. Aseprite MCP Live
Source: https://github.com/greenlogs/aseprite-mcp-live
Mechanism: Python MCP server and local Lua/WebSocket extension bind operations to a document and revision, allow previews and undo/redo, and optionally edit animation frames. File saving remains explicit.
Why useful: Lets agents edit an open unsaved Aseprite pixel-art canvas, preserving real layers, history and human edits.
Hackathon adaptation: Generate an editable sprite animation in Aseprite, have a human change a pixel, then let an agent revise the animation without overwriting the new revision.
Flow: Art brief → MCP → Lua bridge → Live editable layers → Review + undo
Limitation: Windows/Aseprite 1.3+ tested. Depends on prior Aseprite MCP work and omits some layer types.

## 4. OmniDR-Bench
Source: https://github.com/Multimedia-Semantic-Analytics-Lab/OmniDR-Bench
Mechanism: 50 bilingual tasks with 6,414 binary rubric leaves across a three-level evaluation tree. Criteria arise from independently gathered video and web evidence, and both model judges and deterministic browser probes grade outputs.
Why useful: New evaluation suite for agents producing time-linked, evidence-backed HTML investigations from videos.
Hackathon adaptation: Create ten robotics-match video research tasks requiring timestamped assertions and cited frames; grade with browser checks and human audit.
Flow: Video+query → HTML report → Timestamp evidence → Atomic rubric → Browser checks
Limitation: An evaluation benchmark rather than a working research agent. Some judgments still depend on a multimodal model.

## 5. Vestigium
Source: https://github.com/Yonagi043/vestigium
Mechanism: Docling OCR builds a structured graph of sections, figures, printed/PDF page numbers, cross-references and terms. Six MCP tools let agents search and read only needed addresses and retain page citations.
Why useful: Local, source-linked navigator for long PDF documents with exact page, section, table and footnote addresses.
Hackathon adaptation: Build a cited VEX rulebook assistant and compare citation accuracy and cost against entire-PDF ingestion.
Flow: PDF/OCR → Address graph → MCP selective reads → Answer → Page audit
Limitation: Developer-run accuracy tests were graded by AI, not humans. Similar hierarchical retrieval exists; other clients largely untested.
